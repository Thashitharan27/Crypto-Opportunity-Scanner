# Saved Strategy Configurations

This folder is intentionally kept clean for current Crypto Strategy Lab configuration files.

Old pre-Stage-26 configurations were removed because the strategy/profile schema changed substantially during development. Create and save fresh configurations from the current application instead of reusing the retired files.

Suggested naming:

- `BTCUSDT_4H.json`
- `ETHUSDT_15m.json`
- `SOLUSDT_4H_research.json`

Use subfolders later only when they provide a clear purpose, such as `final/`, `research/`, or `paper/`.
