# Crypto Opportunity Scanner

Crypto Opportunity Scanner is an independent project bootstrapped from the
current `main` branch of
[`Thashitharan27/Crypto-Strategy-Lab`](https://github.com/Thashitharan27/Crypto-Strategy-Lab).

This initial baseline intentionally preserves the Crypto Strategy Lab platform
and its existing trading semantics. It does not yet contain the Opportunity
Scanner or code from Volatility Paper Bot. Package-level names remain unchanged
where possible so that later renaming and refactoring can be performed
deliberately.

## Baseline scope

The baseline is intended to retain the upstream platform's:

- Data Lake and data-quality systems;
- feature system and caching;
- research and backtesting infrastructure;
- immutable runs and provenance;
- MCP integration; and
- GUI infrastructure and existing test suite.

Development of Opportunity Scanner functionality will begin in a subsequent
change, after this known-good baseline has been established.
